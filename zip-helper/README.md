# やさしいZIP解凍

Windows標準の「すべて展開」で日本語のファイル名が文字化けするZIPを、別の文字コードで読み直して解凍する小さなアプリです。

## 使い方

1. Python 3.11以降（tkinterを含む通常のWindows版）を用意します。
2. `やさしいZIP解凍.py` を実行します。
3. ZIPを選び、一覧でファイル名を確認します。
4. 名前が読める文字コード（自動、UTF-8、CP932）を選びます。
5. 「この内容で解凍…」を押して保存先を選びます。

ZIP自体は書き換えません。自動判定は一般的なケース向けの簡易判定です。暗号化ZIPや特殊なZIP形式には対応していません。
